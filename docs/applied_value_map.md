## **What this map does not claim**

**Not a market.** Affinity is structural resonance with a record-shape, not demand. The analogous column names spaces with the right record-shape — not customers, not competitors beaten.

**Not a reading it cannot prove.** Every Reading cell is green (deployed output, traceable) or grey (held open). No reading is reported from plausibility, memory, or construction. Grey cells fill only when a run log or screenshot is in hand.

**Not value separated from proof.** Every capability cell is confirmed live in code, or it is not in the map.

**Not the unbuilt scales.** Trajectory-scale is flagged underpowered (curriculum row). The relational multi-author scale is absent — not yet built, so not in the map.

*The frame surfaces affinities and reports only proved readings. The same discipline that runs through the instrument: read what is there, decide nothing that is not, and hold the gap open rather than fill it.*
